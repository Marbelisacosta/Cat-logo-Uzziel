# **App Name**: Click Shop

## Core Features:

- Public Product Catalog: Browse the public catalog without login, viewable by all users.
- Role-Based Login: Log in as Customer, Employee (validation key: empleadovip2024), or Administrator (validation key: superadmin2024) to access specific functionalities. Login sessions are persistent. (Note: currently only Google Fonts are supported.)
- Admin Dashboard: Provide access for administrator to fully manage all the operations (inventories, billing, taxes, users).
- Smart Catalog: Filter products by the users height and gender selected at signup to suggest appropriate products.
- Activate Notifications: Popup window at the start of the app allowing users to activate notifications about latest products.
- Stock Management: Enable employee role to update the stock information.

## Style Guidelines:

- Background color: Light desaturated puce (#F7F0EF). Evokes sophistication with warmth, serving as a gentle backdrop that complements other hues.
- Primary color: Gold (#E3A737), reflecting quality. Used for main interactive elements.
- Accent color: Burnt Orange (#91390B), used for call to action and to create contrast and emphasize specific elements, for a look that evokes warmth and energy.
- Body font: 'PT Sans', a sans-serif to convey modern and neat content presentation. Headlines: 'Playfair' for fashion and style appeal.
- Fixed bottom menu for Home, Categories, Offers and Support. Top section includes links to Settings, Profile and Login/Register.
- Use minimalist and modern icons for navigation and key actions, supporting the overall clean aesthetic.
- Incorporate subtle transition animations when navigating between pages to create smooth user experience.
